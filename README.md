# EventMaster — игры и викторины для мероприятий (MVP)

Kahoot-подобное веб-приложение для ведущих: ведущий показывает на экране QR-код, гости
сканируют его со своих телефонов и играют вместе в реальном времени.

## Что уже умеет MVP

- **Авторизация ведущих** — регистрация/вход по email + пароль (JWT).
- **Игроки без регистрации** — вход в игру по 6-значному PIN и имени.
- **Викторина** — вопросы с 2–4 вариантами ответа, один правильный; очки за правильность +
  бонус за скорость; таблица лидеров.
- **Живое голосование (poll)** — вопрос с вариантами, результаты на экране в реальном времени.
- **QR-код** — на экране ведущего в лобби игры; по нему открывается сайт с игрой.
- **Экран ведущего** — для показа на проекторе: PIN, QR, игроки, вопросы, живые результаты,
  лидерборд, финальный подиум, «играть снова».
- Ведущий может обновить страницу — игра сохранится (переподключение в течение 2 минут).

## Технологии

- **Backend**: Node.js + Express + Socket.IO + SQLite (`node:sqlite`, без внешней БД)
- **Frontend**: Vite + React + React Router, `socket.io-client`, `qrcode`
- Один сервис: в продакшене Express раздаёт собранный клиент и WebSocket.

## Запуск локально

Нужен Node.js 20+ (проверялось на Node 24).

```bash
# 1. Зависимости (из корня репозитория)
npm run setup

# 2. Собрать клиент
npm run build

# 3. Запустить сервер (http://localhost:3001)
npm start
```

Для разработки с горячей перезагрузкой (два процесса):

```bash
npm run dev:server   # API + WebSocket на :3001
npm run dev:client   # Vite dev-сервер на :5173 (проксирует /api и /socket.io)
```

База данных — файл `server/data/app.db` (создаётся автоматически). В комплекте тестовый
аккаунт ведущего: **test@example.com / secret1** с демо-викториной.

## Как провести игру

1. Зарегистрируйтесь как ведущий → «Создать» → выберите тип (викторина или голосование).
2. Добавьте вопросы и варианты. В викторине отметьте галочкой правильный ответ.
3. Нажмите «Запустить» — откроется экран с **QR-кодом и PIN**.
4. Покажите этот экран на проекторе. Гости сканируют QR (или заходят на сайт и вводят PIN)
   и вводят имя.
5. Нажмите «Начать игру». Управление: «Показать результаты» → «Следующий вопрос» → финал.

## Как расшарить (дать попробовать другому)

### Вариант 1: деплой в облако (ссылка работает у всех)

Проще всего — [Render](https://render.com) (бесплатный tier, один сервис):

1. Залейте проект в Git-репозиторий (GitHub/GitLab).
2. В Render: **New → Web Service**, подключите репозиторий.
3. Настройки:
   - **Build Command**: `npm run setup && npm run build`
   - **Start Command**: `npm start`
   - Добавьте **Persistent Disk**, примонтированный к `/opt/render/project/server/data`
     (иначе база очищается при рестарте).
4. Получите ссылку вида `https://ваш-сервис.onrender.com` — она и есть ссылка для гостей,
   QR-коды сгенерируются сами с этим адресом.

Альтернативы: Railway, Fly.io — те же команды.

### Вариант 2: показать с локальной машины (ngrok)

```bash
npm start
# в другом терминале:
ngrok http 3001
```

Ngrok выдаст публичный HTTPS-адрес — по нему откроется приложение, пока запущен туннель.

## Структура

```
server/          Express + Socket.IO + SQLite
  src/index.js   точка входа, раздача клиента
  src/auth.js    регистрация/вход, JWT
  src/quizzes.js REST API викторин и опросов
  src/game.js    realtime-логика игры (комнаты по PIN, очки, лидерборд)
  src/db.js      схема SQLite
client/          React-приложение (Vite)
  src/pages/     Landing, AuthPage, Dashboard, QuizEditor, HostGame, PlayGame
server/test-flow.mjs  сквозной тест игрового цикла (node test-flow.mjs при запущенном сервере)
```
