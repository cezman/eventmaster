### Блок 8 — Простая админка пользователей (ветка `EM-14`, идея владельца от 2026-08-30)
> Делать после Блока 2 (нужен его rate limit) и желательно после Блока 5 (админка редактирует те же поля профиля).
- колонка `role` в `users` (`'host'` по умолчанию, `'admin'`) — идемпотентная миграция; middleware `adminRequired` поверх `authRequired`
- админ назначается вручную SQL-ом на ВМ (`UPDATE users SET role='admin' WHERE email=...`) — без UI-самоназначения
- страница `/admin` (только `role='admin'`): список пользователей (email, имя, дата регистрации, число квизов), редактирование имени/email, сброс пароля (выдать новый), блокировка (`status: 'active'|'blocked'`) и удаление (каскад почистит его квизы — FK уже настроены)
- Socket.IO admin-ui из `index.js` — это другое (dev-инструмент сокетов), с ним не смешивать
