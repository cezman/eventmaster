# Экономия квоты облачного агента (записано 2026-08-31)

Подписка считает «промпты за 5 часов», но в агентном режиме промпт ≈ весь накопленный
контекст, пересылаемый при **каждом** ходе. Экономится не число сообщений, а объём
контекста: строка, попавшая в чат, дорожает на каждом следующем шаге.

## Реальные размеры файлов этого проекта

| Файл | Строк | ~Токенов | Как читать |
|---|---|---|---|
| `AGENTS.md` | ~75 | ~1k | грузится сам в каждый чат — не раздувать |
| `ROADMAP.md` | ~125 | ~2.5k | верх («Текущий этап» + «Как брать работу»), остальное по нужде |
| `client/src/styles.css` | ~1470 | ~15k | **никогда целиком**: `grep -n '^/\*' client/src/styles.css` → Read offset/limit |
| `client/src/pages/PlayGame.jsx` | ~455 | ~5k | прицельно |
| `server/src/game.js` | ~382 | ~4k | прицельно |
| `client/src/pages/HostGame.jsx` | ~310 | ~3k | прицельно |
| `client/src/pages/QuizEditor.jsx` | ~290 | ~3k | прицельно |

Полное чтение на старте чата (ROADMAP + styles.css + пара страниц) ≈ 25–30k токенов
до первой строчки работы, и этот объём пересылается каждым ходом: сеанс из ~10 ходов
обходится в 200k+. Прицельный старт — 3–5k, разница примерно в 6 раз.

## Шаблон первого сообщения для новой ветки

```
Ветка EM-22: <задача одной строкой>.
Контекст: ROADMAP.md — только «Текущий этап» и «Как брать работу» (верх файла).
Файлы по задаче: <например client/src/cabinet/GamesSection.jsx, класс .quiz-card в styles.css>.
Разведку — субагентом Explore, большие файлы читать кусками (правила в AGENTS.md).
```

Чем конкретнее указаны файлы — тем меньше агент прочитает «на всякий случай».

## Правила (продублированы в AGENTS.md, агент соблюдает их сам)

1. `styles.css` и файлы >200 строк — только прицельно: grep → Read с offset/limit.
2. Разведку «посмотри всё» — субагенту Explore: он читает в своём контексте, в основной
   чат возвращается выжимка.
3. Скриншоты — не в основной чат (визуальные скиллы/judge); в чат только вердикт.
   Опционально: грубую проверку скриншотов можно отдавать локальной модели в LM Studio
   (glm-4.6v-flash, http://localhost:1234/v1) — вообще без облачных токенов.
4. Одна задача — один чат; длинный сеанс не продолжать новой задачей.
5. Вывод длинных команд (сборка, e2e) сокращать до сути.

## Чего НЕ экономить

- Ревью субагентом перед каждым PR (конвенция AGENTS.md) — контроль качества, стоимость оправдана.
- E2e-прогон `node server/test-flow.mjs` перед PR.

## Ориентир по планам (август 2026)

GLM Coding Lite ≈ 120 промптов/5 ч, Pro ≈ 600 промптов/5 ч (+недельные капы); Claude
Pro ≈ 45 сообщений/5 ч, Max 5x/20x ≈ 225/900. С прицельным стартом (~3–5k токенов)
даже Lite хватает на несколько итераций за окно; с полным чтением файлов одна итерация
съедала заметную долю окна.
